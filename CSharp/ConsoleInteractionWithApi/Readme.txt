Приложение разработано в качестве выполнения тестового задания.

Это консольное приложение, которое может обращаться Api сервиса: https://open-meteo.com/

В приложении пользователь управляет функционалом посредством команд. Есть следующие команды:
	getweather - получение данных о погоде в заданной точке (широта и долгота) на текущий момент. Обязательно указывать широту, долготу.
		Пример: getweather /55.75 /37.6
	getweatheri - получение данных о погоде в заданной точке (широта и долгота) в инетрвал дат по часам. Обязательно указывать широту, долготу и 2 даты (даты начала и конца).
		Пример: getweatheri /55.75 /37.6 /18.11.2024 /24.11.2024
	save - сохранение только что полученных данных в файл (.csv). Есть возможность указать путь к файлу. Если путь не указан, то будет записан в файл базовую директорию с названием ConsoleInteractionWithApi.csv
		Пример: save /E:\file1.csv
	readfile - чтение данных из файла. Данные читаться в прямом порядке. Есть возможность указать путь к файлу и количество строк для чтения и вывод в консоль.
		Если путь не указан, то чтение будет производится из файла по умолчанию (как указано в пункте про запись). В будущем можно было бы добавить реверсивное чтение.
		Пример: readfile /E:\file1.csv /n 12
	q или Q - выход из приложения.
	? - справка.

Есть возможность выполнять запрос на текущие параметры погоды (температура, ветер (скорость и направление), относительная точка росы). 
Эти параметры можно расширить:
	расширив структуру BaseWeatherData
	добавив это расширение в OpenMeteoParse (классы Current и Hourly) для упрощённого парсинга JSON посредством System.Text.Json
	добавив необходимый класс маппинга для корректной работы парсера и записи в файл csv посредством CsvHelper
